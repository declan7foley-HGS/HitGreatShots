# Hit Great Shots .com PWA

## Local
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
npm run preview
```

## Deploy to Vercel
Push this folder to GitHub, import the repository into Vercel, and deploy. Vercel detects Vite automatically.

## Data
Saved sessions use browser `localStorage` key `golf-shot-tracker-sessions`. Data therefore remains device/browser-local and is not cloud backed up.
